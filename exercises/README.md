## 新练习的结构

- `README.md`：题目、自己的思路、验证结果和复习问题。
- `main.c`：C 实现；多文件程序按实际需要扩展。
- Rust 练习采用 Cargo 项目结构，保存 `Cargo.toml` 和源码。

需要保留错误版本时，用 Git 提交记录，并在学习日志中引用提交编号。只有实际完成后才更新练习状态。
