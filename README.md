# 编程学习资料

## 如何使用

1. 开始学习时，把 `学习档案.md` 交给教练。
2. 练习代码保存到 `exercises/` 对应目录。
3. 结束学习时更新档案，并在 `学习日志.md` 追加实际表现。
4. 更换工具或模型时，提供档案、最近的日志和当前代码，使用档案末尾的启动消息。

完整聊天记录可另外通过所用工具的导出功能保存；没有导出功能时，可复制到本地文件作为备份。日常交接优先使用简短档案，不必提供全部历史对话。

建议定期把此文件夹复制到自己的备份位置；模型并不一定能自动访问前一个工具的聊天记录或本地文件，需要你主动提供。

## 使用 Git 保存学习进度

此目录是独立的本地 Git 仓库，主分支为 `main`。

每次学习结束，更新档案、日志和代码后，在此目录运行：

```bash
git status
git diff
git add 学习档案.md 学习日志.md exercises/
git commit -m "记录本次练习和学习进度"
```

修改使用说明时，也把 `README.md` 加入提交。每次提交描述实际完成的练习或修改。

查看历史：

```bash
git log --oneline
git show <提交编号>
```

Git 提交保存本地版本历史。要防止电脑故障造成丢失，仍需另外备份此目录（包含隐藏的 `.git` 目录），或后续配置远程仓库。
