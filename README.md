保存学习状态、练习代码和实际能力证据，支持在不同工具或模型之间继续学习。

## 文档导航

| 分类 | 入口 | 用途 |

| 学习路线 | [C → Rust 路线](learning/roadmap.md) | 阶段目标和推进依据 |

## 目录结构

```text
learning/              当前档案与学习路线
journals/              日志索引及按年份保存的学习记录
exercises/             练习索引及按语言保存的练习
  c/001-max-count/     第一题：最大值与出现次数
  rust/                开始 Rust 练习时创建
templates/             可复制的文档模板
guides/                工具操作与参考说明
```

## 开始或继续学习

先阅读[学习档案](learning/profile.md)，从其“下一步”开始。当前练习是[001：最大值与出现次数](exercises/c/001-max-count/README.md)。

更换模型或工具时，提供学习档案、最近一份日志和当前练习代码，使用档案末尾的启动消息。工具无法访问本地文件时，手动上传或复制相关内容。

## 每次学习结束

1. 保存代码，并在练习文档填写思路与验证结果。
2. 从模板建立日志，在日志索引新增链接。
3. 更新学习档案中的状态、能力证据和下一步；同步练习索引中的状态。
4. 检查 Git 改动，提交并推送。

## 文档约定

- 路径使用英文小写，内容使用中文；目录入口统一为 `README.md`。
- 日志按年份归档，练习按语言和编号归类。
- 跨文档引用使用相对链接，便于本地阅读和 GitHub 浏览。
- 当前状态维护在学习档案中；题目细节放在练习目录；历史过程放在日志中。
- 完整聊天记录如需保存，可放在 `archives/conversations/`，按日期和主题命名，并从相关日志链接。需要时再创建该目录。
- 能力记录以独立完成、提示后完成、尚未掌握等实际表现为依据。
