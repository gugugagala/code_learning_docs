# C → Rust 学习路线

路线按实际掌握情况推进，不以固定天数作为升级条件。

| 阶段 | 重点 | 练习方向 | 进入下一阶段的依据 |
|---|---|---|---|
| C 基础表达 | 条件、循环、函数、数组 | 最大值、计数、查找 | 能独立写步骤和代码，并解释结果 |
| C 数据处理 | 字符串、结构体、边界 | 字符统计、联系人管理 | 能处理常见边界和无效输入 |
| C 内存与排错 | 指针、生命周期、动态内存 | 动态扩容、错误定位 | 能解释内存归属并定位典型错误 |
| C 小项目 | 文件读写、模块组织、错误处理 | 可保存和读取的联系人程序 | 能维护程序并适应需求变化 |
| Rust 入门 | Vec、String、match、Option、Result | 重写熟悉的 C 练习 | 能解释类型和错误处理方式 |
| Rust 所有权与借用 | 数据生命周期、借用规则 | 重写联系人程序 | 能解释借用报错并调整实现 |


当前阶段和能力证据见[学习档案](profile.md)。
